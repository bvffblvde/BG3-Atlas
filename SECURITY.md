# Security policy

BG3 Atlas is a client side game mod. It does not open network connections, collect data or run outside the game process.

## Reporting a vulnerability

If you find a security issue (for example a way to make the mod or its build tools execute untrusted code), please do not open a public issue. Report it privately through [GitHub security advisories](https://github.com/bvffblvde/BG3-Atlas/security/advisories/new).

You will get a reply within a week. Please give a short description, steps to reproduce and the version or commit you tested.

## Supported versions

Only the latest release and the `main` branch receive fixes.
